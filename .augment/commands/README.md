# CodeForge slash commands

Custom slash commands shared by Claude Code (and Augment, if used) live here.
`.claude/commands` is a directory symlink to this folder, so a command file added
here is picked up by both tools.

None are defined yet. To add one, drop a `<name>.md` file here; it becomes
`/<name>`. Do not name a command `code-review` — it clashes with Claude Code's
built-in `/code-review`.
